# Project guidance

- Etui is a dependency-free Swift 6 / AppKit application for macOS 26+; prefer native APIs. The `Pinyin` input method is the one exception: it loads librime and rime-ice, which `make ime` downloads at pinned versions into `.local/` and bundles; `Sources/CRime` vendors only librime's C headers.
- `Launcher.swift` owns panel lifecycle and input; `Views.swift` owns presentation and the shared panel chrome (`PanelStyle`, `Row`, `GlassPanel`, `Tap`, `keyAction` routing) used by panels; `Catalog.swift`, `Rank.swift`, and `History.swift` own discovery, matching, and persistence; `Calculator.swift` owns arithmetic parsing and result formatting for launcher queries; `Text.swift` owns byte-level string primitives shared by them; `Window.swift` owns frontmost-window tiling; `Switcher.swift` owns switch targets (windows of running apps across Spaces, Google Chrome tabs read through `osascript`, and Combe tabs read through Accessibility), reloaded each time the launcher opens; `Clipboard.swift` and `ClipPanel.swift` own pasteboard capture (history, selection grabs, synthesized copy/paste) and the clip panel; `Translate.swift` owns the translate config, the OpenAI-shaped chat client, and the translator; `TransPanel.swift` owns the translate panel and its geometry; `Screenshot.swift` owns area and window selection, freezing each display before the selection overlay, scrolling capture and stitching, and copying captures into clipboard history; `Markup.swift` owns the post-capture markup editor (rectangle, arrow, and text marks in image pixel coordinates, shared on-screen and export rendering), opened from the screenshot toolbar for area and window captures, overlaying the captured region in place at 1:1 whenever the region fits within the screen's frame, keeping its toolbar inside the visible frame and falling back to centered scaling only when the region extends past the screen.
- `Sources/Pinyin` is a separate InputMethodKit bundle (`Pinyin.app`, `me.samzong.inputmethod.Pinyin`); a lone Shift toggles its English mode, shared across apps: `Main.swift` loads librime and starts the IMK server, `Controller.swift` maps key events to Rime and updates marked text, and `Candidates.swift` owns the candidate panel. `Resources/Pinyin` holds its `Info.plist`, localized names (`Pinyin` / `拼音`), menu icon, and the Rime data layered over rime-ice. `pinyin.dict.yaml` imports only its Chinese dictionaries (no Tencent vocabulary); `rime_ice.custom.yaml` drops English and mixed-word candidates, keeps learned words in `rime_ice.userdb`, and defaults to English punctuation; `default.custom.yaml` selects the schema and sets nine candidates per page. `make ime` prebuilds the dictionaries and ships only the compiled `build/`, not the dictionary sources.
- Catalog entries are apps from the application folders plus System Settings panes from `/System/Library/ExtensionKit/Extensions` (extension point `com.apple.Settings.extension.ui`); panes open through `x-apple.systempreferences:<bundle id>`.
- `ClosedLid.swift` owns the independent closed-lid system setting: read `IOPMrootDomain`'s `SleepDisabled`, authorize fixed `pmset` commands through macOS, and verify the applied state. This setting persists outside Etui; do not treat it as a process-owned assertion or implicitly reset it at startup or exit.
- `Display.swift` owns the persisted external-monitor switch, physical-display checks, built-in display configuration, and recovery process. It loads SkyLight and CoreDisplay at runtime. Keep recovery ready before disabling the built-in display; display configuration scope alone does not restore it after a crash.
- Search uses exact, prefix, and word-prefix matching plus learned aliases and usage; preserve the Unicode behavior covered by existing checks.
- User data lives in `~/Library/Application Support/Etui/{aliases,usage,hidden}.json` plus `clipboard/` (`index.json` and `blobs/`), `rime/` (the input method's Rime user data and learned words), the `externalDisplayOnly` preference in UserDefaults, and `translate.json` (`base`, `key`, `model`, optional `extra` merged into the request body, `styles` with optional per-style `model` and `extra` overrides); use temporary directories for persistence checks.
- Run `make check` for code changes; extend `Tests/EtuiTests/Checks.swift` for uncovered behavior.
- Verify UI changes in the native app, including affected hotkey, focus, dismissal, input-method bypass in the search field, and launch behavior; tests alone do not prove these.
- `make app` packages locally; `make install` replaces `/Applications/Etui.app`, opens it, and may register a login item, so use it only when installation is requested.
- `make ime` packages `.local/dist/Pinyin.app` with prebuilt dictionaries; `make install-ime` replaces `~/Library/Input Methods/Pinyin.app` and registers it, and `make uninstall-ime` removes it. Verify input method changes by selecting it in a native text field, a browser, a terminal, and an Electron app; macOS requires adding it once under System Settings > Keyboard > Input Sources.
- Keep scratch files and distribution artifacts under `.local/`; use `make dmg` for disk images.
